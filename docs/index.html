Architecture

Where’s the film?

▣ ⇄ ▣We both have itEach browser plays its own copy. Play, pause, seek and speed changes travel between viewers.
Browser ⇄ WebSocket ⇄ Browser

Fastify matches the filenames and byte sizes. Each player opens its local file and the sync engine uses timed peer messages to correct drift.

▣ → ▤Only I have itOffer the file to your partner. Compatible formats can start playing while the rest arrives.
File → DataChannel → Player

The room relays WebRTC signaling. The browser sends the bytes over the negotiated connection, with TURN relay support when configured. Other containers finish transferring before playback.

▤ → ▷Share my screenChoose a window or screen on your desktop. Your partner watches the live stream.
Screen → MediaStream → Viewer

The sharing browser captures the selected surface with your permission. The receiving player follows the stream. Available audio sources depend on your browser and operating system.
